BOT Chain Mainnet (Chain ID 677)

Warden records verified phishing reports directly on BOT Chain Mainnet (Chain ID 677). Every confirmed report is stored permanently on-chain, creating a transparent and tamper-resistant security ledger that can be verified by anyone.

Solidity Smart Contract

Warden uses an immutable Solidity smart contract deployed on BOT Chain Mainnet to permanently record verified phishing reports. Every report is stored transparently on-chain and cannot be modified after confirmation.

AI Security Engine (Gemini AI)

Warden utilizes Google's Gemini AI and Groq Cloud as its primary phishing detection engine to analyze submitted URLs. The AI ​​evaluates domains, detects phishing patterns, and classifies each URL before the user decides whether to submit a blockchain report.
